# Персонажи

Каждый персонаж знает только **свой кусок** истории. Игрок собирает сюжет, разговаривая со всеми по очереди,
поэтому в карточке персонажа всегда есть раздел «Что знает» — это то, что он может рассказать герою и когда.

## Шаблон карточки

```

Роль, где живет / где найти, когда появляется.
## Кто он
## Характер и манера речи
## Что знает (и в каком квесте расскажет)
## Чем помогает (игровая механика)
## Квесты
## Примеры реплик
```

## Второстепенные жители

Прохожие в городе и соседи в поселках (уже есть в игре) тоже могут дать подсказку. Их реплики короткие и
бытовые, но в каждом поселке и районе города должен быть хотя бы один житель, который что-то видел:
машину без номеров у реки, свет в подвале лаборатории ночью, незнакомцев у дома Анны Петровны.
Такие подсказки не обязательны для прохождения, но помогают игроку, который застрял.
