# Локации

Все места игры, их назначение и где они находятся. Мир круглый (радиус 1100, центр `worldCenter` в
`src/engine/layout.js`), трасса идет с запада на восток, река с мостом пересекает ее у города.

| Файл | Локация | Зачем нужна |
| --- | --- | --- |
| [villages.md](villages.md) | 4 поселка: Сосновка, Заречье, Каменка, Береговое | Дом героя, дом бабушки и Веры, кузница, поселок у лаборатории |
| [grandma-house.md](grandma-house.md) | Дом Анны Петровны, двор, участок, овраг, дерево, домик на дереве | База героя |
| [city.md](city.md) | Город | IT-компания, полиция, автомастерская, хлебозавод, школа, жители |
| [library.md](library.md) | Библиотека и информационный центр (в городе) | Книги, знания, интернет, архив |
| [mall.md](mall.md) | Торговый центр (на трассе) | Провизия, ингредиенты эликсира, детали |
| [gas-station.md](gas-station.md) | Бензоколонка (на трассе у ТЦ) | Бензин, дизель для генератора |
| [river.md](river.md) | Река, мост, берега, лес | Место гибели Веры, тайники детства, боссы |
| [laboratory.md](laboratory.md) | Лаборатория на закрытой территории | Финал: попасть можно только в самом конце |

## Схема (предложение по расположению)

```
                          север
            Каменка (кузница, карьер)
                 ·
                 ·            лес
  запад                                                     восток
  Сосновка ════ трасса ═══ заправка ═ ТЦ ═══ ГОРОД ═╪═ мост ═╪═ ЗАРЕЧЬЕ
  (дом героя)                                       река     (дом Анны Петровны,
                                                     ║        овраг, домик на дереве)
                                        Береговое ···║
                                                     ║
                                      [ЛАБОРАТОРИЯ — закрытая территория, забор]
                          юг
```

Сосновка и Заречье стоят на противоположных концах трассы: первая долгая поездка через всю карту —
квест «К бабушке».

## Сверка с текущей сборкой

Сейчас в игре: один поселок (`src/locations/village/village.js`, x = −1300), шесть городов
(`src/locations/city/city.js`: два на трассе у x = 220 и 520, четыре на севере и юге), торговый центр
и заправка на трассе, река с мостом (x = 350). Предлагаемое соответствие:

| Сейчас | По сюжету |
| --- | --- |
| Поселок (x = −1300) | Сосновка, дом героя (уже отмечен как свой) |
| Город на трассе x = 220 | Город: библиотека, IT-компания, полиция, автомастерская |
| Город на трассе x = 520 (за рекой) | Заречье, дом Анны Петровны |
| Северный город x = −900 | Каменка, кузница и карьер |
| Южная часть у реки | Береговое и закрытая территория лаборатории |
| Остальные три города | Районы города или убрать; решить при реализации |

Координаты здесь — предложение, при реализации их можно двигать. Документация код не меняет.
