# Приборы героя

Список приборов и откуда они берутся — в [docs/story/quests/devices.md](../story/quests/devices.md). Здесь —
как они работают в игре. Приборы в мире (генератор, верстак, серверы) — это станции, см.
[items-and-crafting.md](items-and-crafting.md#станции-в-мире).

## Как это видит игрок

- Прибор — вещь в инвентаре (`kind: 'device'`). Собранные приборы попадают на **панель приборов**: ряд из
  4 ячеек внизу экрана, клавиши **1–4** (в диалоге цифры выбирают ответ, вне диалога — прибор).
- Нажатие включает прибор (или срабатывает один раз), повторное — выключает.
- Эликсир можно варить повторно: после задания 2.05 установка синтеза Веры в домике на дереве (станция `synth`) за три игровых часа пополняет шкалу на 40 единиц (не больше полной). Это стандартное действие станции, без квеста (`src/content/buildings/treehouse.js`).
- Почти все приборы тратят **эликсир**: у прибора свой заряд, а заряжают его на верстаке в домике
  (`charge`), или прямо из инвентаря, если эликсир с собой.
- Над панелью видно заряд, а когда прибор включен, экран меняется (тепловизор, сетка анализатора).

## Прибор — это вид + параметры

Код знает несколько **видов** приборов. Конкретный прибор — данные: вид, заряд, что он дает.

| Вид | Что делает | Приборы |
| --- | --- | --- |
| `vision` | пока включен, меняет картинку и показывает скрытое: сущности и точки с нужным тегом | тепловизионные очки |
| `scan` | наводишь на человека, существо или точку — карточка: пульс, раны, слабые места, улики | анализатор тканей |
| `projectile` | выстрел по направлению взгляда, попадание дает тег цели | сетемет |
| `area` | действует вокруг героя на радиус | ионизатор-громоотвод, резонатор, глушитель регенерации |
| `trap` | ставится на землю, срабатывает, когда через нее проходят | масляная ловушка |
| `passive` | работает сам, пока лежит в инвентаре или включен | наушники, экранированный кейс, браслет |
| `heal` | лечит героя или другого | регенератор |
| `world` | особое действие с миром: две точки и переход | портал |
| `upgrade` | апгрейд машины, а не вещь в руках | композитный кузов |

```js
defineDevice('thermal', {
  name: 'Тепловизионные очки', kind: 'vision', icon: 'goggles',
  capacity: 5, drain: { perMinute: 1 },          // 1 заряд в игровую минуту, пока включены
  overlay: 'thermal',                            // картинка экрана: какой фильтр включить
  tags: ['reveal:invisible'],                    // что прибор делает с целями (см. ниже)
  reveals: ['hidden:warm'],                      // точки и сущности с этим тегом становятся видны
});

defineDevice('analyzer', {
  name: 'Анализатор тканей', kind: 'scan', icon: 'analyzer',
  capacity: 3, drain: { perUse: 1 }, range: 12,
  tags: ['reveal:clones', 'weakpoint:regen'],
});

defineDevice('net_gun', {
  name: 'Сетемет', kind: 'projectile', icon: 'net', capacity: 4, drain: { perUse: 1 },
  range: 40, tags: ['ground:fly', 'stun:3s'],
});

defineDevice('headphones', { name: 'Шумоподавляющие наушники', kind: 'passive', tags: ['immune:hypnosis'] });

defineDevice('bracelet', { name: 'Браслет сохранения', kind: 'passive', tags: ['rewind'], capacity: 1,
  drain: { perUse: 1 } });     // срабатывает сам перед смертью, заряд — эликсир
```

## Браслет возврата (сделан)

Первый прибор в коде: `src/player/devices.js` (реестр `DEVICES`, `defineDevice`, `wearDevice`, `hasDeviceTag`),
модель на руке — `src/models/devices.js`.

- Браслет не лежит в инвентаре: когда его берут, он **надевается на левое запястье** и виден на модели героя
  (`player.attach('wristL', mesh)` в `src/models/person.js`).
- У него тег `saves`. **До браслета сохранений нет вообще**: ни быстрых слотов под инвентарем, ни панели
  в раскрытом инвентаре. С браслетом они появляются (`hasDeviceTag('saves')` в `src/player/inventory.js`).
- Надетые приборы пишутся в сохранение (`devices`). Загрузка — это возврат с памятью, поэтому надетое сейчас
  не снимается.
- Пока голубятни (3.04) нет, в игре браслет лежит дома, на письменном столе в кабинете на втором этаже.
  В ДЕМО — на подставке «Приборы» за столом предметов: E надевает (браслет исчезает с подставки), еще раз E у пустого места снимает и кладет обратно.
- Возврат к началу стычки (тег `rewind`) появится вместе с боем.

## Теги: как приборы связаны с боссами, точками и людьми

Прибор ничего не знает о конкретных боссах. Он выдает **теги** (`reveal:invisible`, `ground:fly`,
`break:armor`). Способности существ и точки в мире ждут нужный тег (см. [combat.md](combat.md#способности)).
Поэтому новый прибор против нового босса — это две записи данных, а связь между ними — одно слово.

| Тег | Прибор | Что снимает |
| --- | --- | --- |
| `reveal:invisible` | тепловизор | невидимость (Тень) |
| `reveal:clones` | анализатор | копии-иллюзии (Эхо) |
| `weakpoint:regen` | анализатор | показывает точку перегрузки регенерации (Гидра) |
| `stop:regen` | глушитель регенерации | регенерацию (Гидра) |
| `ground:fly` | сетемет | полет (Сокол) |
| `slow:speed` | масляная ловушка | сверхскорость (Вспышка) |
| `immune:magnet` | композитный кузов | притяжение железа (Магнит) |
| `cancel:storm` | ионизатор | грозу и молнии (Туча) |
| `immune:emp` | экранированный кейс | управление электроникой (Искра) |
| `immune:hypnosis` | наушники + эликсир ясности | гипноз (Шепот) |
| `break:armor` | резонатор | броню (Глыба) |
| `rewind` | браслет | смерть: возврат к началу стычки |

## Приборы вне боя

Те же теги работают в мире:

- точка с `visibleWith: 'thermal'` или `hidden: 'warm'` видна только в очках (следы в лесу, 3.03);
- `scan` по персонажу или телу показывает карточку из данных (`scan: { text, reveal }` у точки или существа);
  так анализатор дает улики (синяки на запястьях, 2.08);
- условие `device:thermal` в квесте — «игрок смотрит в очках прямо сейчас».

## Новый прибор

1. Чертеж и прибор — в `items.js`, рецепт — в `recipes.js`.
2. `defineDevice` с подходящим видом и тегами.
3. Если вид новый — это новая механика: модуль в `src/mechanics/devices/`.
