# Квесты

Все квесты игры по актам, **от самого простого к самому сложному**. Игрок не знает сюжета заранее: каждый
квест дает ему один-два новых факта, и из них он сам собирает историю (какой факт где раскрывается —
[reveal-map.md](reveal-map.md)). Приборы, которые герой собирает по ходу, описаны в [devices.md](devices.md).

| Файл | Акт | Что происходит |
| --- | --- | --- |
| [act-1-morning.md](act-1-morning.md) | 1. Утро | Герой просыпается, едет к реке, узнает о гибели Веры, находит домик на дереве |
| [act-2-traces.md](act-2-traces.md) | 2. Следы | Опрос людей, первые находки, первый эликсир и прибор, первый босс |
| [act-3-devices.md](act-3-devices.md) | 3. Приборы | Сервера, сборка приборов, боссы 2–7, становится ясно, что это убийство |
| [act-4-laboratory.md](act-4-laboratory.md) | 4. Лаборатория | Боссы 8–10, портал, Громов, проникновение в лабораторию, Барон, артефакт |
| [act-5-past.md](act-5-past.md) | 5. Прошлое | Возвращение в прошлое, вместе с Верой против Штерна, эпилог |

## Как растет сложность

| Акт | Что требуется от игрока |
| --- | --- |
| 1 | Одна цель за раз, всё рядом, подсказка в журнале прямо говорит, куда идти. Учит управлению, машине, заправке, разговорам |
| 2 | Несколько людей, порядок свободный. Журнал говорит «узнать», а не «пойти туда». Первый крафт (эликсир) и первый простой прибор |
| 3 | Прибор собирается из 3–4 источников (книга, сервер, Михалыч, ингредиенты). Боссы требуют конкретного прибора. Несколько цепочек параллельно |
| 4 | Ресурсы и время: дизель, мощности серверов, ночь. Защита базы. Боссы требуют двух приборов. Нужно связать улики самому |
| 5 | Всё вместе: все приборы, весь эликсир, без права на ошибку (кроме браслета) |

## Журнал заданий

Журнал всегда можно открыть (предлагаемая клавиша **J**, она свободна; плюс кнопка-книжка рядом с инвентарем).
Пока открыт журнал, игра на паузе, как в диалоге.

Разделы журнала:

1. **Задания** — активные квесты. У каждого: название, короткая цель («Поговорить с Денисом у моста»),
   список шагов с галочками, где выдан. Одно задание можно отметить как текущее: его точка видна на миникарте.
2. **Выполненные** — архив, можно перечитать.
3. **Выводы** — записи героя о том, что он понял. Появляются, когда игрок узнал факт сюжета (см.
   [reveal-map.md](reveal-map.md)). Пишутся сухим языком героя, а с ростом героя становятся теплее.
   Это и есть «воссозданный» игроком сюжет.
4. **Люди** — карточка на каждого знакомого: кто это, где найти, что он уже рассказал.
5. **Чертежи и рецепты** — найденные чертежи приборов и рецепты эликсира, что для них уже есть и чего не хватает.

Формат записи в журнале (как это видит игрок):

```
Домик на дереве                                    [Акт 1]
Цель: Найти домик на дереве за оврагом у дома Анны Петровны
 ✓ Расспросить Анну Петровну
 ✓ Перейти овраг
 ○ Забраться в домик
Выдала: Анна Петровна, Заречье
```

Для кода (позже): квест — `{ id, act, title, goal, steps: [{ text, done }], giver, location, reveals: [факты], unlocks: [квесты] }`,
сохраняется вместе с остальной игрой в `captureGame/applyGame`.

## Шаблон квеста

```
### 1.03 Название
- Выдает: кто / что запускает
- Где: локация
- Цель в журнале: …
- Шаги: …
- Игрок узнает: факты (Ф-номера из reveal-map)
- Награда: вещи, доступ, приборы
- Открывает: следующие квесты
```
