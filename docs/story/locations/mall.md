# Торговый центр

На трассе у въезда в город (уже есть в игре: `src/locations/city/mall.js`, интерьер `src/models/mall-interior.js`).
Директор — Людмила Сергеевна Орлова.

- **Зачем:** провизия (еда, вода, аптечки), ингредиенты эликсира, детали для приборов (медь, батареи, электроника).
- **Кабинет директора** на втором этаже: список покупок Веры, разговоры о поставках.
- **Подсобка:** ночью сюда носят ящики «для лаборатории» (3.02, бой с Эхо).
- **Телевизор в зале:** местные новости, где иногда мелькает Штерн.
- Парковка у здания (уже есть).
