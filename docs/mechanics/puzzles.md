# Головоломки на весь экран (2D)

Разгадать или собрать: сварить эликсир, собрать прибор, склеить фотографию, найти ошибку в коде, подобрать
код к тайнику, связать улики. Головоломка открывается поверх игры на весь экран, в 2D.

## Как это видит игрок

- Экран затемняется, поверх — 2D-сцена на весь экран: заголовок, поле, подсказка снизу, кнопка «Закрыть» (Esc).
- Пока головоломка открыта, игра на паузе: время не идет, клавиши игры не работают (как в диалоге).
- Управление мышью: перетаскивать, кликать, крутить колесом; часть видов — клавишами.
- Решил — короткая анимация, звук, головоломка закрывается, срабатывают действия `onSolve`.
- Закрыл или ошибся — `onFail` (обычно ничего: можно попробовать еще раз). Прогресс внутри головоломки
  не сохраняется, если не сказано `keepProgress: true`.
- Подсказка: кнопка «?» показывает `hint`; в сложных — после нескольких ошибок подсказки становятся точнее.

## Устройство

- `src/mechanics/puzzles/overlay.js` — оверлей: `<canvas>` на весь экран поверх `renderer`, пауза,
  Esc, кнопки, подсказки, масштаб под размер окна (поле рисуется в своих координатах 1280 × 720 и
  вписывается в экран).
- `src/mechanics/puzzles/kinds/*.js` — **виды** головоломок, каждый пишется один раз.
- Конкретная головоломка — данные: вид + параметры + картинки + действия.

```js
definePuzzle('elixir_brew', {
  kind: 'sequence',
  title: 'Эликсир',
  background: 'workbench',                 // assets/puzzles/workbench.png или процедурный фон
  hint: 'Записи Веры: «Сначала тепло, потом соль. Медь — последней, и не дай закипеть».',
  params: {
    pieces: ['heat', 'water', 'honey', 'sea_salt', 'sugar', 'reagent', 'copper_wire', 'stir'],
    answer: ['water', 'heat', 'honey', 'sea_salt', 'sugar', 'stir', 'reagent', 'copper_wire'],
    mistakesAllowed: 2,
  },
  onSolve: [{ give: { elixir: 3 } }],
});
```

Вид получает `params` и маленький API:

```js
definePuzzleKind('sequence', {
  create(params, api) {
    // api.sprite(name), api.draw.text/box/image, api.sound(name), api.solve(), api.fail(), api.hint(level)
    return {
      draw(ctx, t) {},         // каждый кадр
      pointer(e) {},           // down / move / up в координатах поля
      key(e) {},               // клавиши
    };
  },
});
```

## Виды

| Вид | Что делает игрок | Параметры | Где в сюжете |
| --- | --- | --- | --- |
| `sequence` | выбирает действия в правильном порядке | `pieces`, `answer`, `mistakesAllowed` | эликсир (2.05), эликсир ясности, запуск генератора |
| `choice` | выбирает один ответ из нескольких (с картинкой или кодом) | `question`, `image` / `code`, `answers`, `correct` | ошибка в коде пекарни (2.01), проекты Олега |
| `assembly` | перетаскивает детали в нужные гнезда на схеме | `slots: [{ id, x, y, accepts }]`, `parts` (часть — из инвентаря), `blueprint` | сборка анализатора, очков, браслета, кейса |
| `jigsaw` | собирает картинку из кусков | `image`, `grid: [4, 3]`, `rotate` | фотографии у Анны Петровны (1.05), рваная газета в архиве (3.06) |
| `wires` | соединяет контакты, не пересекая провода | `nodes`, `pairs` | серверная (3.10), щиток в ТЦ ночью (3.02) |
| `lock` | крутит диски или набирает код | `dials`, `code`, `symbols` | тайники Веры, сейф Штерна |
| `cipher` | расшифровывает записку по ключу | `text`, `key`, `method: 'caesar' / 'substitution' / 'grid'` | записки Веры, переписка Штерна |
| `rhythm` | жмет в такт (меха горна, станок) | `beats`, `tempo`, `tolerance` | помочь у горна (2.08), ковка корпусов |
| `spot` | ищет на картинке нужное (отличия, улику) | `image`, `targets: [{ x, y, r, text }]` | осмотр тела (1.03), обысканный дом (1.05), кабинет Штерна |
| `board` | связывает улики нитками с выводами | `cards` (из инвентаря, `kind: 'evidence'`), `claims`, `links` | письмо Громову (4.07), доска у Дениса |
| `route` | прокладывает путь по схеме | `map`, `start`, `goal`, `obstacles` | проход мимо дронов (4.08), подземные цеха по чертежу |
| `sliding` | двигает плитки | `image`, `size` | замки в лаборатории |

Новый вид — новый файл в `kinds/`. Остальные головоломки этого вида — только данные.

## Части из инвентаря

У `assembly` и `board` часть деталей берется из инвентаря: `parts: [{ item: 'copper' }, { item: 'lens' },
'spring', 'board']`. Если нужной вещи нет, ее гнездо показывается пустым с подсказкой («Нужна линза —
у Людмилы в ТЦ»), и головоломку нельзя решить. Вещи забираются только при решении (`consume: true`).

Так сборка прибора у Михалыча может быть и заказом с ожиданием, и головоломкой, где игрок собирает
прибор сам: это выбирается в рецепте полем `puzzle`.

## Картинки

- По умолчанию — **процедурная 2D-графика** на canvas (прямоугольники, линии, текст) в той же простой
  манере, что и сцена; пиксельные значки вещей берутся из `PIXEL_ART` (`src/player/icons.js`) и
  увеличиваются без сглаживания. Этого достаточно для `sequence`, `choice`, `wires`, `lock`, `rhythm`, `cipher`.
- Для `jigsaw`, `spot`, `assembly` нужны картинки: `assets/puzzles/<имя>.png` (или `.svg`). Нет картинки —
  вид рисует заглушку с подписью, чтобы головоломку можно было проверить до того, как нарисован арт.
- Картинка для `jigsaw` и `spot` может рисоваться прямо из 3D-сцены: снимок рендера с нужной камеры
  (`api.snapshot('grandma.room')`). Так «фото Сокола» и «осмотр тела» не нужно рисовать отдельно.

## Где открывается

- из диалога: `do: [{ puzzle: '2.08.bellows' }]`;
- со станции: `opens: { puzzle: '4.09.door' }`;
- из рецепта: `puzzle: 'elixir_brew'`;
- из карточки вещи: `read: { puzzle: 'note_vera_1' }` (зашифрованная записка);
- из точки в мире: `do: [{ puzzle: '1.03.body' }]`.

Результат приходит событием `puzzle { id, result }`, поэтому шаг квеста просто ждет `done: 'puzzle:2.08.bellows'`.
