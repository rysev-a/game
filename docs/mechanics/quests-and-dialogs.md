# Квесты, журнал, персонажи, диалоги

Язык условий (`if`) и действий (`do`) — в [core.md](core.md).

## Квест

```js
defineQuest({
  id: '2.08',
  act: 2,
  title: 'Анализатор',
  giver: 'blueprint',            // кто выдал: id персонажа или слово для журнала
  requires: ['done:2.07'],       // когда квест вообще может начаться
  autoStart: 'has:bp_analyzer',  // начаться сам, когда это станет правдой (иначе — действием { start })
  goal: 'Собрать анализатор тканей',
  steps: [
    { id: 'find_smith', text: 'Найти, кто сделает корпус', done: 'talked:mihalych',
      hint: 'В городе говорят, в Каменке есть кузнец' },
    { id: 'bring', text: 'Привезти Михалычу чертеж и медь', done: 'step:2.08.bring', marker: 'kamenka.forge' },

**Торговля.** Магазин — данные в файле квеста: `shops: { stalls: { title, greeting, goods: [{ item, price, if, do }] } }`, ссылка `'2.13.stalls'` (`src/core/shops.js`). Открывает его действие `{ shop: '2.13.stalls' }`, обычно из варианта ответа торговца в диалоге (торговец — человек мира `world.people`). Окно (`src/quests/shop-ui.js`) показывает товары как ячейки инвентаря с ценой, сверху кошелек; клик по товару покупает: деньги (`money`) уходят, предмет оказывается в инвентаре (`give`), `do` товара выполняется следом; купленное повторно не продается. В сценариях: `{ shop: '2.13.stalls', buy: ['sg_pipe'] }`; логику покупки проверяет `tests/shops.test.js`.

Шаг может назвать человека, над которым появляется ромбик (как над Денисом в первом задании): поле `target: 'lyudmila'` или список `[{ who: 'lyudmila', if: '!has:vibranium' }, { who: 'mihalych', if: 'has:vibranium' }]` (цель только пока выполнено условие). Шаг с `beacon: 'boxes'` показывает над своей меткой большой мигающий значок с коробками (курьер 2.15): он виден, пока герой вне зоны метки, и исчезает, когда он въехал в нее (`updateBeacon` в `src/quests/guide.js`). Человек с `done: 'talked:<id>'` подсвечивается и без `target`. Ромбик видно и внутри здания, если человек на том же этаже (`personByChar` в `src/quests/guide.js`).
    { id: 'forge', text: 'Помочь у горна', done: 'puzzle:2.08.bellows' },
    { id: 'charge', text: 'Заправить анализатор эликсиром', done: 'has:analyzer' },
  ],
  reveals: ['Ф17'],              // факты, которые квест обязан открыть (проверка для reveal-map.md)
  onDone: [{ reveal: 'Ф17' }, { give: { money: 0 } }, { flag: 'denis_sees_bruises' }],
  unlocks: ['3.01'],             // для журнала и проверки: эти квесты становятся доступны
});
```

- **Шаги** выполняются, когда их условие `done` становится правдой. По умолчанию шаги идут по порядку
  (следующий виден, когда выполнен прежний); `order: 'any'` — все видны сразу, в любом порядке (2.03).
- `done` у шага — условие, а `puzzle:…`, `fight:…`, `talk:who.node` — короткие формы для «это событие
  произошло с результатом успех».
- `count: 5` у шага — счетчик «0/5» (2.03, пять свидетелей); каждый `{ step: '2.03.witness' }` прибавляет 1.
- `marker` — место, которое показывается на миникарте, пока шаг текущий.
- `hint` — что журнал скажет, если игрок застрял (виден через какое-то время или по кнопке).
- `onStep: { forge: [...] }` — действия при выполнении конкретного шага.
- `fail` — условие провала (4.05: дом найден) и `onFail`.
- `optional: true` — побочное задание (поручения соседей, гонки с Рустамом).

Больше в файле квеста ничего обязательного нет. Квест 2.08 целиком (с репликами Михалыча и головоломкой у
горна) — ниже, в разделе [пример](#пример-квест-208-целиком).

## Журнал

`J` или кнопка-книжка у инвентаря. Пока журнал открыт, игра на паузе (как диалог). Всё содержимое журнала
**собирается из данных**, отдельно его писать не нужно:

| Раздел | Откуда |
| --- | --- |
| Задания | активные квесты: `title`, `goal`, видимые `steps` с галочками, `giver`, место выдачи |
| Выполненные | квесты с `state: 'done'` |
| Выводы | открытые факты: текст записи — в `src/content/facts.js` (`defineFact('Ф17', { text })`) |
| Люди | персонажи, с которыми говорил, + что они уже рассказали (`facts`, открытые в их диалогах) |
| Чертежи и рецепты | рецепты, чей чертеж есть у игрока, с галочками по `needs` (см. [items-and-crafting.md](items-and-crafting.md#рецепт)) |

Формат записи — как в [docs/story/quests/README.md](../story/quests/README.md#журнал-заданий).

## Персонаж

Именованные персонажи (Михалыч, Николай Палыч, Людмила Сергеевна…) описываются данными и сами появляются
в мире. Случайные прохожие и соседи остаются как есть (`npcs`, `talk.js`), им только добавляются слухи.

```js
defineCharacter({
  id: 'mihalych',
  name: 'Михалыч',
  title: 'кузнец',
  look: { preset: 'elderly', options: { shirtColor: 0x5a4632, apron: true } },  // createPerson(preset, options)
  // Где он в какое время. Без расписания — всегда в home
  schedule: [
    { time: '07:00-20:00', at: 'kamenka.forge' },
    { time: '20:00-23:00', at: 'kamenka.porch', seated: true },
    { time: '23:00-07:00', at: null },          // спит — в мире нет
  ],
  dialog: 'mihalych',                           // откуда брать реплики
  crafter: 'mihalych',                          // делает вещи по рецептам с at: 'mihalych'
  likes: ['pies'],                              // можно отдать — скажет спасибо (общий ответ)
});
```

Персонажа можно переставить действием `{ person: { mihalych: 'kamenka.quarry' } }` (4.04) и спрятать
`{ person: { mihalych: null } }`. Разговор начинается так же, по E рядом (`nearestPerson` в `talk.js`
учитывает и именованных).

## Диалог

Движок окна остается прежним (`src/engine/dialogue.js`: узел `{ speaker, text, options }`). Новое — узлы
берутся из данных, а `src/mechanics/dialogs.js` превращает их в узлы движка: проверяет `if`, выполняет `do`,
переходит по `goto`.

```js
defineDialog('mihalych', {
  // С чего начинается разговор: первый подходящий вход
  start: [
    { if: '!talked:mihalych', goto: 'meet' },
    { if: 'night', goto: 'late' },
    { goto: 'hub' },
  ],
  nodes: {
    meet: {
      text: 'Максим? Вымахал. Раньше ты только смотрел, как я кую. Чего пришел?',
      options: [{ text: 'Здравствуйте, Григорий Михайлович.', goto: 'hub' }],
    },
    late: { text: 'Ночь на дворе. Завтра приходи.', options: [{ text: 'Хорошо.', end: true }] },
    hub: {
      text: ['Говори, не стой.', 'Ну?', 'Чего тебе?'],   // список — случайная реплика
      options: ['topics', 'orders', 'give', { text: 'Ничего, зайду позже.', end: true }],
    },
  },
  // Темы: варианты, которые появляются в hub по условию. Квесты добавляют свои темы
  topics: [
    { text: 'Что за грузовики ездят по ночам?', if: 'done:3.10', goto: 'trucks', once: true },
  ],
});
```

Узел:

| Поле | Что |
| --- | --- |
| `text` | реплика; список — случайная; `{ if, text }` в списке — по условию |
| `speaker` | по умолчанию имя персонажа («Михалыч — кузнец») |
| `do` | действия, когда узел показан |
| `options` | варианты ответа (до 9) |
| `next` | узел без вариантов: «E — продолжить» и переход сюда |

Вариант ответа:

| Поле | Что |
| --- | --- |
| `text` | что говорит герой |
| `if` | показывать только если |
| `do` | действия при выборе |
| `goto` | следующий узел (`'hub'`, или `'2.08.bring'` — узел из файла квеста) |
| `end: true` | закончить разговор |
| `once: true` | после выбора больше не показывать |
| `give: 'bp_analyzer'` | отдать вещь: вариант виден, только если она есть; при выборе забирается и идет событие `give` |
| `show: 'photo_sokol'` | показать вещь: то же, но вещь остается |
| `reveal: 'Ф17'` | короче, чем `do: [{ reveal }]`; заодно отмечает в «Людях», что это рассказал он |

Особые варианты в `options` — строки:

- `'topics'` — все темы персонажа и темы, которые добавили активные квесты;
- `'orders'` — заказы мастеру: «Сделай: Анализатор тканей» для рецептов, чертеж которых есть
  (см. [items-and-crafting.md](items-and-crafting.md#мастера-и-заказы)), и «Забрать: …» для готовых;
- `'trade'` — обмен и покупка (Людмила, Рустам, Николай Палыч);
- `'give'` — «Отдать / показать вещь…»: открывает инвентарь на выбор. Ответ персонажа на конкретную вещь —
  в `reactions` (ниже), иначе общий («Это мне ни к чему»).

```js
defineDialog('denis', {
  ...,
  reactions: {
    photo_sokol: { show: true, goto: '3.05.photo' },   // показать: вещь остается
    pies: { goto: 'thanks_pies', take: true },          // отдать: забрать
  },
});
```

### Темы из квеста

Квест добавляет свои реплики к чужим персонажам, не трогая их файлы:

```js
defineQuest({
  id: '2.08',
  ...,
  topics: {
    mihalych: [
      { text: 'Сможете сделать корпус по чертежу?', if: ['has:bp_analyzer', '!step:2.08.bring'], goto: '2.08.bring' },
    ],
    passerby: [   // любой прохожий в городе
      { text: 'Не знаете, кто тут умеет делать корпуса для приборов?', if: ['at:city', '!talked:mihalych'],
        goto: '2.08.rumor_smith' },
    ],
  },
  nodes: {        // узлы, которые нужны только этому квесту, зовутся '2.08.<имя>'
    rumor_smith: { text: 'В Каменке кузнец есть, Михалыч. Он что хочешь сделает.', do: [{ track: '2.08' }],
      options: [{ text: 'Спасибо.', end: true }] },
    ...
  },
});
```

Темы видны, пока квест активен. Когда квест выполнен, его темы исчезают сами.

### Слухи

Прохожие и соседи (`passerby`, `resident`, `officer`, `cashier`, …) получают общий список слухов: короткие
подсказки, которые зависят от хода истории (docs/story/characters/README.md, «Второстепенные жители»).

```js
defineRumor({ who: 'resident', at: 'kamenka', if: ['quest:3.03', '!beaten:ten'],
  text: 'В лесу кто-то ветки ломает, а никого не видно. Грибники не ходят.' });
```

Вариант «Вы ничего не слышали?» появляется у прохожего, если есть подходящий слух.

## Пример: квест 2.08 целиком

`src/content/quests/2-08-analyzer.js` — всё, что нужно, чтобы квест работал. Новые вещи (`bp_analyzer`,
`copper`, `analyzer`) лежат в `items.js`, рецепт — в `recipes.js`, головоломка `bellows` — вид `rhythm`,
он уже есть в механиках.

```js
defineQuest({
  id: '2.08',
  act: 2,
  title: 'Анализатор',
  giver: 'Чертеж Веры',
  autoStart: 'has:bp_analyzer',
  goal: 'Собрать анализатор тканей',
  steps: [
    { id: 'find_smith', text: 'Найти, кто сделает корпус', done: 'talked:mihalych',
      hint: 'Спросите в городе, кто умеет работать с металлом' },
    { id: 'bring', text: 'Привезти Михалычу чертеж и медь', done: 'step:2.08.bring', marker: 'kamenka.forge' },
    { id: 'forge', text: 'Помочь у горна', done: 'puzzle:2.08.bellows', marker: 'kamenka.forge' },
    { id: 'pick', text: 'Забрать анализатор у Михалыча', done: 'has:analyzer', marker: 'kamenka.forge' },
  ],
  onDone: [{ reveal: 'Ф17' }, { start: '3.01' }],

  topics: {
    passerby: [{ text: 'Кто тут умеет делать корпуса для приборов?', if: ['at:city', '!talked:mihalych'],
      goto: '2.08.rumor' }],
    mihalych: [
      { text: 'Сможете сделать корпус по чертежу?', if: '!step:2.08.bring', goto: '2.08.blueprint' },
      { text: 'Я готов. Где меха?', if: ['step:2.08.bring', '!step:2.08.forge'], goto: '2.08.forge' },
    ],
  },

  nodes: {
    rumor: { text: 'В Каменке кузнец, Михалыч. Он что хочешь сделает.', options: [{ text: 'Спасибо.', end: true }] },
    blueprint: {
      text: 'Покажи. Хм. Чертеж кривой, но мысль правильная. Медь есть?',
      options: [
        { text: 'Вот чертеж и медь.', if: 'has:copper>=2', show: 'bp_analyzer', do: [{ take: { copper: 2 } },
          { step: '2.08.bring' }], goto: '2.08.wait' },
        { text: 'Меди пока нет.', if: '!has:copper>=2', goto: '2.08.no_copper' },
      ],
    },
    no_copper: { text: 'Без меди никак. В торговом центре спроси, у Людмилы.', options: [{ text: 'Понял.', end: true }] },
    wait: {
      text: 'Приходи завтра. Нет, сегодня. Садись, раздувай горн.',
      options: [{ text: 'Сажусь.', goto: '2.08.forge' }, { text: 'Позже.', end: true }],
    },
    forge: { text: 'Ровно дуй. Не части.', do: [{ puzzle: '2.08.bellows' }] },
    after: {
      text: 'Корпус к утру остынет. Заливай свое зелье и забирай.',
      do: [{ order: 'analyzer' }],     // заказ: готов утром, забрать — вариант «Забрать: Анализатор»
      options: [{ text: 'Спасибо, Григорий Михайлович.', end: true }],
    },
  },

  puzzles: {
    bellows: { kind: 'rhythm', title: 'Горн', beats: 12, tempo: 70, tolerance: 0.18,
      background: 'forge', onSolve: [{ dialog: '2.08.after' }], onFail: [{ say: { who: 'mihalych',
      text: 'Не части, говорю. Еще раз.' } }] },
  },
});
```

Этого достаточно: журнал покажет шаги, миникарта — кузницу, прохожие подскажут дорогу, Михалыч заберет медь,
откроется горн, утром анализатор можно забрать, а «Выводы» получат запись Ф17. Кода в квесте нет.
