# Персонажи: лист и модели

[characters.png](characters.png) — лист из Figma с 20 low-poly персонажами. По нему собраны модели людей в
`src/models/person.js`: граненые детали без контуров, плоская заливка, которую оттеняет свет сцены.
Каждый персонаж — набор в `PERSON_PRESETS`, создается так: `createPerson('vera')`.
Все сразу, сеткой как на листе: `src/models/characters.html`.
