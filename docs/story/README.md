# Документация по сюжету

Здесь собрано всё, что нужно, чтобы строить игру по сюжету: история, персонажи, квесты и локации.
Код игры эти документы не меняют, это план, по которому дальше пишутся диалоги, квесты и места.

## Главный принцип: игрок не знает сюжета

Полная история из [STORY.md](STORY.md) **никогда не показывается игроку целиком**. Игра начинается с того,
что герой просыпается у себя дома и выходит на улицу. Всё остальное игрок собирает сам:

- из **разговоров** с людьми вокруг (каждый знает свой кусочек и рассказывает его по-своему);
- из **находок** (записки, переписка на ноутбуке, чертежи, фотографии, вещи в местах, где герой играл с девушкой в детстве);
- из **воспоминаний** героя, которые всплывают в ключевых местах (короткие сцены-вспышки);
- из **журнала заданий**, куда герой сам записывает выводы.

Поэтому каждый факт сюжета привязан к конкретному квесту, человеку или месту. Карта «какой факт где
раскрывается» — в [quests/reveal-map.md](quests/reveal-map.md).
