# Карта раскрытия сюжета

Каждый факт из [STORY.md](../STORY.md) игрок узнает в определенном месте. Когда факт открыт, в разделе
«Выводы» журнала появляется запись героя. К концу игры из выводов складывается вся история.

Правило: **ни один важный факт не раскрывается одним человеком целиком**. Каждый кусочек подтверждается
хотя бы двумя источниками (разговор + находка), чтобы игрок не пропустил его.
