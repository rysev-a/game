# Первая версия: абсолютно линейная игра

> Сначала делаем самую простую игру от начала до конца: герой идет по цепочке подсказок, побеждает главного
> злодея и спасает девушку. Ни побочных квестов, ни развилок. Всё остальное растет вокруг этой готовой линии.

Язык данных (условия, действия, события) — в [core.md](core.md), квесты и диалоги — в
[quests-and-dialogs.md](quests-and-dialogs.md). Здесь — что из них входит в первую версию и какие квесты
собирают тонкий срез сюжета.

## Что входит, что нет

| Входит в v1 | Не входит (позже) |
| --- | --- |
| Одна сюжетная цепочка, квесты идут строго по порядку | Побочные квесты |
| Шаги внутри квеста тоже строго по порядку | Развилки, выбор, разные исходы |
| Каждый квест — один файл с данными, кода нет | Игра за другого персонажа (например за Веру) |
| Подсказки: каждый квест открывает следующую | Таймеры и поражение вертолетом (после первых трех квестов) |
| Бой, головоломки, вождение, договоры с людьми, сборка приборов | Шаблоны побочных квестов, `roles`, `world` |
| Поле `meta` у любой записи (движок его не читает) | Типизация `meta` |

Если механика нужна квесту, ее добавляют в тот момент, когда до этого квеста дошла очередь, и не раньше.

## Цепочка квестов

Девять квестов из существующего сюжета ([docs/story/quests](../story/quests/README.md)), номера сохранены.
Остальные квесты сюжета в v1 не делаем: нужные им факты и вещи выдают соседние квесты цепочки.

| # | Квест | Подсказка, которую получает игрок | Что проверяет |
| --- | --- | --- | --- |
| 1 | **1.03 У моста** | утонула Вера, это девочка из детства | диалог, сцена у реки (уже есть), вождение |
| 2 | **1.06 Домик на дереве** | Вера и была «ученой»; тайники; рюкзак | дальняя поездка, овраг, лазание, находки |
| 3 | **2.05 Первый эликсир** | эликсир — топливо приборов | крафт, головоломка «порядок действий» |
| 4 | **2.08 Анализатор** | на запястьях Веры следы рук (убийство) | договориться с Михалычем, головоломка у горна, первый прибор |
| 5 | **2.11 Погоня — Вспышка** | им нужен ноутбук Веры, начальник лаборатории причастен | вождение (погоня), первый босс, ловушка |
| 6 | **3.04 Браслет** | чертеж в голубятне, браслет возвращает во времени | прибор по чертежу, сервер, сохранения как сюжет |
| 7 | **4.09 Лаборатория и Барон** (4.08 пропуск, 4.09 дверь, 4.10 Барон) | тайная дверь, цех, плазмомет | скрытный проход, зал капсул, бой с боссом |

### Что нужно построить под эту цепочку

Порядок внедрения, в котором появляется новое:

1. **Ядро** (`story`, `check()`, `run()`, реестр, сохранения v2, журнал, маркер на карте) и квест 1.03 на нем.
   Сцена у реки (`incident.js`) подключается как есть: ее завершение — событие, которое отмечает шаг.
2. **Диалоги из данных** (`defineDialog`, `topics`): квесты 1–2.
3. **Крафт и головоломки** (`defineRecipe`, `definePuzzle`, вид «порядок» и «ритм»): квесты 3–4.
4. **Стычки**: бой и вождение через общий `encounter`: квест 5. Босс и ловушка как взаимодействие с предметом.
5. **Приборы и сервер** (`defineDevice`): квесты 4, 6, 8.
6. **Зал капсул и финал**: квесты 7–9. Здесь же добавляются таймеры и вертолет, если они понадобятся (например
   ночной пропуск 4.08).

После каждого пункта игра проходится от начала до последнего готового квеста. Недоделанные квесты в игру не
подключаются.

| Где | Что |
| --- | --- |
| `src/core/` | реестр, условия, действия, квесты и шаги, диалоги из данных, журнал, `checkContent`, сценарии прохождения |
| `src/content/` | факты Ф1–Ф3, персонаж Денис, квест 1.03 (`quests/1-03-bridge.js`) |
| `src/quests/` | подключение к игре: хост (инвентарь, часы, положение), место `bridge.scene`, обертки над функциями игры (`hooks.js`), окно журнала, метка на карте |
| `tests/` | `npm test`: тесты ядра, проверка содержания и сценарий `tests/scenarios/1-03-bridge.js` |
| `quests.html` | игра с квестами, пока загрузчик не добавлен в `index.html` |

Подключение без правки старых файлов: `src/quests/hooks.js` оборачивает функции игры (`captureGame`, `rootDialogue`,
`spawnIncident`, `drawMapView` …). Когда старые файлы можно будет править, в конец `index.html` добавляется строка
`<script src="src/quests/load.js"></script>`, обертки переезжают на свои места (список в шапке `hooks.js`), а `quests.html` удаляется.

Запуск: `npm test`. Игра с квестами: `python3 -m http.server`, затем `/quests.html`. В консоли: `questGame.state`, `questGame.journal()`.

## Формат квеста в v1

Файл `src/content/quests/<номер>-<имя>.js`, один вызов `defineQuest`. Функций внутри нет.

```js
defineQuest({
  id: '2.08',
  title: 'Анализатор',
  goal: 'Собрать анализатор тканей',        // короткая цель для журнала
  next: '2.11',                              // следующий квест цепочки
  steps: [                                   // идут строго по порядку
    { id: 'find_smith', text: 'Найти, кто сделает корпус', done: 'talked:mihalych' },
    { id: 'bring',      text: 'Привезти Михалычу чертеж и медь', done: 'step:2.08.bring', marker: 'kamenka.forge' },
    { id: 'forge',      text: 'Помочь у горна', done: 'puzzle:2.08.bellows' },
    { id: 'pick',       text: 'Забрать анализатор', done: 'has:analyzer', marker: 'kamenka.forge' },
  ],
  topics: { mihalych: [ /* реплики этого квеста у других персонажей */ ] },
  nodes: { /* узлы диалога этого квеста */ },
  puzzles: { bellows: { kind: 'rhythm', /* ... */ } },
  onDone: [{ reveal: 'Ф17' }, { start: '2.11' }],
  meta: {},                                  // что угодно, движок не читает
});
```

Поля v1: `id`, `title`, `goal`, `next`, `steps` (с `id`, `text`, `done`, `marker`, `hint`), `topics`, `nodes`,
`puzzles`, `encounters`, `interactions`, `onDone`, `meta`. Все остальное из
[quests-and-dialogs.md](quests-and-dialogs.md) (`requires`, `autoStart`, `order: 'any'`, `optional`, `fail`) в
v1 не нужно: порядок задает `next`.

### Поле `meta`

Есть у любой записи (`defineQuest`, `defineItem`, `defineCharacter`, …). Правила:

1. **Движок не читает `meta`** и не проверяет. Логики там нет: условия и действия живут только в настоящих полях.
2. Значения — любой JSON. В сохранения не попадает: это содержание, а не состояние.
3. Ключи с префиксом: `design.`, `balance.`, `ui.`, `author.`, `audio.`, `todo.`.
4. `checkContent()` печатает перепись ключей `meta` и сколько записей их используют.
5. Ключ, который встретился в 5 и более записях и нужен коду, повышается до настоящего поля (скриптом
   миграции).

## Что растет потом

Каждый шаг делается, когда предыдущий уже играется целиком:

1. **Удлинение основной линии**: новые квесты в середине цепочки (остальные квесты сюжета). Формат тот же,
   меняется только `next`.
2. **Побочные квесты**, которые можно не выполнять: `optional`, шаблоны `defineQuestTemplate`, `roles`.
3. **Таймеры, поражение вертолетом, мир квеста** (`world`: объекты, живущие пока квест активен).
4. **Развилки и исходы** (`outcomes`, выборы с последствиями), игра за других героев (например за Веру).

Всё это расширяет формат квеста новыми необязательными полями; квесты v1 продолжают работать без правок.
