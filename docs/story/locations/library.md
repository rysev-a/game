# Библиотека и информационный центр

В городе, на центральной улице. Старое двухэтажное здание с колоннами.

| Зал | Что там |
| --- | --- |
| Абонемент | Семён Аркадьевич выдает книги. Книги открывают чертежи и рецепты |
| Читальный зал | Любимое место Веры; ее стол у окна |
| **Информационный центр** | Безлимитный высокоскоростной интернет: восстановление файлов с ноутбука Веры, поиск людей, письмо Громову |
| Архив (подвал) | Старые газеты и планы зданий: фото Штерна с Бароном, планы старого военного завода |

Квесты: 2.06 «Читательский билет», 3.06 «Архив газет», 4.01 бой с Шепотом, 4.07 «Письмо Громову».
