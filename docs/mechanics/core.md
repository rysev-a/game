# Ядро: состояние, условия, действия, события

Всё остальное (квесты, диалоги, крафт, бой) строится на пяти вещах из этого файла. Их пишут один раз.

## Состояние истории

Один объект, который целиком сохраняется:

```js
const story = {
  flags: {},        // 'met_mihalych': true — что-то произошло
  counters: {},     // 'gen.fuel': 3 — числа: рейсы с дизелем, ночи сервера, деньги не здесь (это предмет)
  facts: {},        // 'Ф17': gameMinutes — какие факты сюжета открыты и когда (reveal-map.md)
  quests: {},       // '2.08': { state: 'active' | 'done' | 'failed', steps: { forge: true }, startedAt }
  orders: [],       // заказы у мастеров: { recipe, at, readyAt } (items-and-crafting.md)
  stations: {},     // 'generator': { state: 'off', ... } — станции в мире
  devices: {},      // 'analyzer': { charge: 3, mode: 'scan' } — приборы героя
  beaten: {},       // 'ten': gameMinutes — побежденные боссы
  people: {},       // 'mihalych': { at: 'kamenka.forge', said: { 'Ф17': true } } — где персонаж и что рассказал
  tracked: '2.08',  // текущее задание: его точка на миникарте
};
```

Инвентарь остается в `inventory` (`src/player/inventory.js`), но становится списком стопок
(см. [items-and-crafting.md](items-and-crafting.md#инвентарь)).

## Условия

Условие — строка, список строк (все должны выполняться) или `{ any: [...] }` (хотя бы одно).
`!` в начале — отрицание. Проверяет одна функция `check(cond)` в `src/mechanics/conditions.js`.

| Условие | Истинно, когда |
| --- | --- |
| `has:copper` | в инвентаре есть медь |
| `has:elixir>=2` | эликсира хотя бы 2 (также `>`, `<`, `<=`, `=`) |
| `flag:met_mihalych` | флаг поставлен |
| `count:gen.fuel>=4` | счетчик |
| `fact:Ф17` | факт открыт |
| `quest:2.08` | квест активен |
| `done:2.08` | квест выполнен |
| `step:2.08.forge` | шаг квеста выполнен |
| `beaten:ten` | босс побежден |
| `at:kamenka` | игрок в месте или зоне (`definePlace` или `registerZone`) |
| `near:kamenka.forge` | игрок в радиусе места |
| `inside` / `driving` | игрок в здании / за рулем |
| `time:22:00-06:00` | игровое время в промежутке (через полночь тоже) |
| `night` / `day` | короткие формы для 22:00–06:00 и 06:00–22:00 |
| `rain` | идет дождь |
| `day:>=2` | идет второй день истории или позже |
| `order:analyzer` | заказ готов и ждет игрока |
| `talked:mihalych` | хоть раз говорил с персонажем |
| `device:thermal` | прибор включен в этом режиме прямо сейчас |
| `state:generator=on` | станция в этом состоянии |
| `puzzle:2.08.bellows` | головоломка решена |
| `fight:3.03.ten` | стычка выиграна |
| `talk:mihalych.analyzer` | игрок дошел до этого узла диалога |
| `hero.hp<30` | здоровье героя (бой) |

```js
if: ['step:2.08.find_smith', 'has:bp_analyzer', '!has:analyzer']
if: { any: ['has:copper>=2', 'flag:lyudmila_supplies'] }
```

Новый вид условия — одна строка в таблице видов в `conditions.js`. Неизвестный вид в режиме `?dev` выводит
предупреждение, а не ломает игру.

## Действия

Действие — объект с одним ключом. Список действий выполняется по порядку. Выполняет `run(effects)` в
`src/mechanics/effects.js`.

| Действие | Что делает |
| --- | --- |
| `{ give: 'analyzer' }`, `{ give: { elixir: 2 } }` | положить в инвентарь (с сообщением «Взято: …») |
| `{ take: 'copper' }`, `{ take: { copper: 2 } }` | забрать |
| `{ flag: 'x' }`, `{ unflag: 'x' }` | флаг |
| `{ add: { 'gen.fuel': 1 } }`, `{ set: { 'gen.fuel': 0 } }` | счетчик |
| `{ reveal: 'Ф17' }` | открыть факт: запись в «Выводах» журнала |
| `{ start: '2.09' }` | выдать квест |
| `{ step: '2.08.forge' }` | отметить шаг выполненным |
| `{ complete: '2.08' }`, `{ fail: '4.05' }` | закончить квест |
| `{ track: '2.08' }` | сделать квест текущим (точка на миникарте) |
| `{ toast: 'Текст' }` | короткое сообщение (`showToast`) |
| `{ phone: { from: 'denis', text: '…' } }` | сообщение на телефон (попадает и в журнал) |
| `{ say: { who: 'mihalych', text: '…' } }` | одна реплика без выбора (окно диалога) |
| `{ dialog: 'mihalych.analyzer' }` | открыть узел диалога |
| `{ puzzle: '2.05.elixir' }` | открыть головоломку на весь экран |
| `{ fight: '3.03.ten' }` | начать стычку |
| `{ order: 'analyzer' }` | сделать заказ у мастера (снимает ингредиенты) |
| `{ station: { generator: 'on' } }` | перевести станцию в состояние |
| `{ person: { mihalych: 'kamenka.quarry' } }` | переставить персонажа в другое место |
| `{ wait: '8h' }`, `{ wait: 'morning' }` | промотать игровое время (`advanceGameTime`), с затемнением |
| `{ teleport: 'treehouse' }` | перенести игрока в место |
| `{ sound: 'river' }` | звук из `audio/` |
| `{ heal: 40 }` | вылечить героя |
| `{ fuel: 0.45 }` | залить бензин в машину рядом (канистра) |
| `{ spot: { 'willow.jar': 'show' } }` | показать / спрятать точку в мире |
| `{ script: 'raft_flashback' }` | именованный сценарий из кода (аварийный люк) |
| `{ if: 'has:x', then: [...], else: [...] }` | ветвление внутри списка |

Новый вид действия — одна функция в `effects.js`.

## События

Механики сообщают о том, что произошло, через `emit(name, data)`. Шаги квестов и триггеры подписываются
на события из данных. После каждого события и каждого действия ядро вызывает `storyChanged()`: условия
шагов перепроверяются только тогда, а не каждый кадр.

| Событие | Когда |
| --- | --- |
| `item` `{ id, n }` | вещь появилась или пропала |
| `talk` `{ who, node }` | игрок дошел до узла диалога |
| `give` `{ who, item }` | игрок отдал вещь персонажу |
| `enter` `{ place }` / `leave` | вошел в место или зону, вышел |
| `hour` `{ hour }` | наступил новый игровой час (сюда же ночь и утро) |
| `puzzle` `{ id, result: 'solved' / 'failed' }` | головоломка закрыта |
| `fight` `{ id, result: 'won' / 'lost' / 'fled' }` | стычка закончилась |
| `order` `{ recipe }` | заказ готов |
| `use` `{ item, on }` | игрок применил вещь (на точку, персонажа, станцию) |
| `device` `{ id, mode, target }` | прибор сработал |

## Триггеры

Когда что-то должно случиться без участия игрока (звонок Олега, погоня Вспышки), — триггер:

```js
defineTrigger({
  id: '2.11.chase',
  when: ['done:2.03', 'done:2.08', 'done:2.10', 'driving', '!at:village'],  // проверяется при storyChanged
  once: true,
  do: [{ start: '2.11' }, { fight: '2.11.vspyshka' }],
});

defineTrigger({
  id: '2.01.call',
  on: 'hour',                       // можно ждать событие
  when: ['done:1.06', 'day:>=2', 'time:09:00-12:00'],
  once: true,
  do: [{ phone: { from: 'oleg', text: 'Ты где? Проект для пекарни горит.' } }, { start: '2.01' }],
});
```

## Места

Данные не знают координат. Локации регистрируют именованные точки, данные ссылаются на имена:

```js
// в src/locations/village/kamenka.js (код локации)
definePlace('kamenka.forge', { x: -820, z: -640, r: 12, name: 'Кузница Михалыча' });
definePlace('kamenka.quarry', { x: -760, z: -720, r: 40, name: 'Карьер' });
```

Место с `floor` и `interior` указывает на этаж здания (как люди в `interiors`). Зоны из `registerZone`
(`village`, `city1`, …) тоже считаются местами в условии `at:`.

## Реестр

Всё содержание регистрируется функциями `define*` в `src/mechanics/story.js`:

`defineItem`, `defineCharacter`, `defineDialog`, `defineQuest`, `defineTrigger`, `definePlace`, `defineSpot`,
`defineRecipe`, `defineStation`, `defineDevice`, `defineCreature`, `defineBoss`, `defineFight`, `definePuzzle`,
`defineScript`.

Каждая функция кладет запись в свою таблицу по `id`. Содержание подключается до `src/engine/game.js`, а
после загрузки всех файлов ядро вызывает `checkContent()`: проверяет, что все ссылки (`has:copper`, `give`,
`goto`, `puzzle`, места) ведут к существующим записям.

## Сохранения

`captureGame` добавляет `story: structuredClone(story)` и инвентарь со стопками. `SAVE_VERSION` становится
`2`; при загрузке слота версии 1 работает миграция: инвентарь `['wrench', ...]` превращается в стопки по 1,
`story` создается пустым, а квесты акта 1 отмечаются по тому, что уже есть (ключи в руках, сцена у реки
пройдена).

Перед боем и перед головоломкой «без права на ошибку» ядро делает **автоснимок** в памяти (не в слот).
Браслет сохранения из сюжета (3.04) — это и есть объяснение сохранений, а после его получения автоснимок
перед боем возвращает игрока к началу стычки с памятью (см. [combat.md](combat.md#поражение)).

## Отладка

Открыть игру с `?dev`:

- `checkContent()` пишет в консоль все битые ссылки;
- `story.dev.start('2.08')` — выдать квест, отметив все нужные ему квесты выполненными;
- `story.dev.give('elixir', 5)`, `story.dev.flag('x')`, `story.dev.reveal('Ф17')`, `story.dev.time('22:00')`;
- `story.dev.puzzle('2.05.elixir')`, `story.dev.fight('3.03.ten')` — открыть сразу;
- в журнале видны скрытые условия шагов.
