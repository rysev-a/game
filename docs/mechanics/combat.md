# Боевой режим

Бои — с синтезированными существами из лаборатории и с боссами (Барон и десять помощников,
[docs/story/characters/bosses.md](../story/characters/bosses.md)). Главное правило сюжета: **босса нельзя
победить в лоб**, нужен свой прибор. В механике это значит: у каждой способности босса есть контр-тег, и
пока он не получен, босс неуязвим или почти неуязвим.

## Как это видит игрок

- Бой идет **в том же 3D-мире**, без отдельного экрана. Когда начинается стычка, вокруг места появляется
  граница арены (кольцо на земле, как у мира — забор), камера встает чуть выше и дальше, музыка меняется.
- Наверху — полоска здоровья героя и сил (выносливость), над врагом — его здоровье и значки способностей.
  Значок способности перечеркивается, когда игрок ее снял прибором: так видно, что прибор подошел.
- Управление (Q, ЛКМ и K уже работают — оружие, [weapons.md](weapons.md); остальное — предложение):

| Клавиша | Что |
| --- | --- |
| W/S, A/D | как обычно: ходьба, поворот |
| Q | достать / убрать оружие |
| R | следующее оружие из инвентаря |
| ЛКМ | с оружием — выстрел по курсору (зажать — очередь); без оружия — удар (серия из трех) |
| K | то же по направлению взгляда, с доводом на ближайшую цель |
| Shift | рывок-уклон, тратит силы |
| 1–4 | приборы с панели |
| E | поднять, бросить, взаимодействовать с ареной (бочка, рычаг) |
| H | съесть еду (пироги) или включить регенератор |

- Цель — враг под курсором, а если курсора нет — ближе всех к направлению взгляда (рамка). Стрелки и зажатое
  колесо мыши крутят камеру, как сейчас.
- Бой на машине (Вспышка, Магнит) — та же стычка, только с `mode: 'car'`: управление как в вождении, урон —
  от столкновений, приборы — ловушки и апгрейды машины.

## Режим боя: как он устроен

Отдельного «экрана боя» нет: бой — это **состояние** героя и места. Их три:

| Состояние | Когда | Что меняется |
| --- | --- | --- |
| **Мирно** | обычная игра | оружие можно достать (Q), но враги не нападают; здоровье тихо восстанавливается |
| **Тревога** | враг заметил героя (`sense.sight` / `hearing`), но стычки нет | враг идет к герою; музыка тише, слышно его; на миникарте — красная точка |
| **Стычка** | `defineFight` начался (шаг в арену, условие квеста) или враг ударил | кольцо арены, камера выше и дальше, полоски здоровья и сил героя, нельзя ездить, путешествовать по карте, сохраняться; время игры идет медленнее (×0,25), чтобы бой не съедал вечер |

**Как начинается стычка.** Либо по сюжету (`defineFight` с местом и условием `when`), либо сама: враг из
`defineCreature` с поведением `chase` дошел до героя и ударил. Во втором случае арена — круг r = 25 вокруг
места первого удара.

**Как кончается.** Цель `win` выполнена (`onWin` — награды и шаг квеста), герой упал (`onLose`), или герой
вышел из кольца, если `canFlee: true` (враги остаются раненными, стычку можно начать снова).

**Один кадр боя.** Ввод → оружие и удары (`src/engine/weapons.js`) → поведение врагов (библиотека
`behavior`) → попадания (`hitTarget` в `src/engine/combat.js`) → способности и их контр-теги → проверка `win`
и поражения → полоски и цифры. Враги, приборы и оружие общаются только через цели и теги, поэтому любой
новый враг сразу «попадаемый», а любое новое оружие сразу по нему бьет.

**Враги бьют героя** тем же языком: удар врага — `hitHero({ damage, type })`, у героя тоже есть `weak`
(например, после регенератора `energy ×0,5`). Попадание по герою — красная вспышка по краям экрана и
отброс; при `hp = 0` — `onLose`.

**Баланс по умолчанию.** Герой 100 здоровья. Ползун (30) — три выстрела лазера или два удара. Босс 200–300:
пока способность не снята — урон ×0,05–0,25 («нельзя в лоб»), после снятия — 15–25 попаданий с перерывами на
перегрев. Перегрев — главный ритм боя: стреляешь, перегрелся — уклоняйся и включай прибор.

## Что уже сделано

- **Цели и урон** — `src/engine/combat.js`: `addCombatTarget`, `hitTarget` с типами урона и `weak`, полоска
  здоровья над целью, цифры урона по цвету типа, вспышка при попадании. Статусы `stagger`, `frozen`, `shock`,
  `burn`, `melt`, толчки, память прошлых позиций, незакрепленные вещи.
- **Оружие** — шесть стволов ([weapons.md](weapons.md)): лазер, гаусс, огнемет, крио, разрядник, тахионный пистолет.
- **ДЕМО: тир** — три манекена (обычный, бронированный, движущийся), три робота, ящики.

## Порядок, в котором строим бой

Каждый пункт — отдельный PR, и каждый сразу проверяется в ДЕМО:

1. **Здоровье героя** (`story.hero.hp`, полоска, `hitHero`, поражение `wake`) + манекен, который бьет в ответ.
2. **Первое существо — ползун** (`defineCreature`, поведения `wander`, `chase`, `lunge`), модель в
   `src/models/creatures.js`; в ДЕМО — круг-арена с ползунами.
3. **Стычка** (`defineFight`: арена, камера, `win: all`, бегство), удар кулаком (`melee`) и рывок-уклон.
4. **Первый босс со способностью** — Глыба (`armor`, снимается `break:armor`): проверяет связку прибор → тег →
   урон оружием.
5. **Браслет в бою**: автоснимок перед стычкой, `onLose: 'rewind'`.

## Существо

Существа из лаборатории — обычные враги: в цехе под лабораторией (4.09), в лесу, у базы (4.05), как
помощники боссов. Описание — данные:

```js
defineCreature('crawler', {
  name: 'Ползун',
  model: 'crawler',                  // 3D-модель в src/models/creatures.js (низкополигональные, как люди)
  hp: 30, damage: 8, speed: 0.16,
  behavior: ['wander', 'chase', 'lunge'],    // поведения из библиотеки, по порядку приоритета
  sense: { sight: 18, hearing: 8 },
  weak: { melee: 1 },                // множители урона
  drops: [{ give: 'chitin', chance: 0.5 }],
  scan: { text: 'Нервная ткань снаружи. Бить сверху.', reveal: null },  // что покажет анализатор
});

defineCreature('swarm_moth', {
  name: 'Мотыльки', model: 'moths', hp: 6, damage: 2, speed: 0.3, count: 8,
  behavior: ['swarm', 'flee_light'], abilities: ['fly'], weak: { area: 3 },
});
```

**Поведения** (`behavior`) — библиотека в коде, каждое пишется один раз: `wander`, `patrol` (по точкам места),
`chase`, `lunge` (прыжок с замахом), `ranged` (плюется издалека), `swarm` (стая), `guard` (стоит у точки),
`flee_light` (боится фонарика), `ambush` (ждет в засаде), `charge` (разбег по прямой), `summon`.

## Способности

Способности есть и у существ, и у боссов. Каждая — модуль в `src/mechanics/combat/abilities/`, а в данных —
просто имя и параметры. Главное у способности — **контр-тег**: какой тег от прибора ее снимает
(таблица тегов — [devices.md](devices.md#теги-как-приборы-связаны-с-боссами-точками-и-людьми)).

| Способность | Что делает | Снимается тегом | Босс |
| --- | --- | --- | --- |
| `speed` | очень быстро бегает, бьет и отскакивает | `slow:speed` | Вспышка |
| `clones` | создает копии-иллюзии; урон получает только настоящий | `reveal:clones` | Эхо |
| `invisible` | не виден, пока не бьет | `reveal:invisible` | Тень |
| `fly` | летает, ближний бой не достает | `ground:fly` | Сокол |
| `magnet` | притягивает и бросает железо, машины | `immune:magnet` | Магнит |
| `storm` | дождь, молнии по арене, туман | `cancel:storm` | Туча |
| `emp` | глушит приборы и машину, выключает свет | `immune:emp` | Искра |
| `hypnosis` | путает управление героя, натравливает союзников | `immune:hypnosis` | Шепот |
| `armor` | урон почти не проходит | `break:armor` | Глыба |
| `regen` | быстро лечится | `stop:regen` (после `weakpoint:regen`) | Гидра |
| `absorb` | берет способность того, к кому прикоснулся | — (бой по фазам) | Барон |
| `summon` | зовет существ | — | любые |

Пока способность не снята, она работает. Если у способности `blocksDamage: true` (невидимость, броня,
копии), урон по боссу почти не проходит — это и есть «нельзя в лоб».

## Босс

Босс — существо с фазами, ареной и наградой:

```js
defineBoss('ten', {
  name: 'Тень',
  model: 'person',                        // помощники Барона — люди: createPerson('…')
  look: { preset: 'adult', options: { coatColor: 0x2b2f2a } },
  hp: 220, damage: 14, speed: 0.22,
  behavior: ['ambush', 'chase'],
  abilities: [{ id: 'invisible', blocksDamage: true }],
  phases: [
    { hpBelow: 0.5, add: [{ summon: 'crawler', count: 3 }], say: 'Ты меня видишь?! Как?' },
  ],
  scan: { text: 'След укола на шее, как у Вспышки.', reveal: 'Ф21' },
});

defineFight('3.03.ten', {
  at: 'forest.kamenka_clearing',
  arena: { r: 35 },
  when: 'night',                          // начинается, только когда условие правда (иначе ждет)
  enemies: [{ boss: 'ten' }],
  hintIfMissing: { 'has:thermal': 'Его не видно. Нужно что-то, что видит тепло.' },
  win: 'boss',                            // boss | all | survive:120s | defend:place | catch | escape
  onWin: [{ give: 'map_caches' }, { reveal: 'Ф22' }, { step: '3.03.beat' }, { say: { who: 'denis',
    text: 'Забираю. Он у меня заговорит.' } }],
  onLose: 'rewind',                       // rewind (браслет) | wake (очнуться у базы, время прошло)
  canFlee: true,
});
```

Цели стычки (`win`) покрывают все бои из квестов:

| Цель | Где в сюжете |
| --- | --- |
| `boss` | большинство боссов |
| `all` | цех под лабораторией (4.09), существа в лесу |
| `survive:120s` | пока серверы считают (4.02) |
| `defend:place` | защита домика и Анны Петровны (4.05) |
| `catch` | погоня за Вспышкой на машине (2.11) |
| `escape:place` | выбраться из цеха до обрушения (5.03) |

Барон (4.10) — тот же босс с фазами: в каждой фазе он берет одну способность из побежденных помощников
(`phases: [{ hpBelow: 0.9, ability: 'speed' }, { hpBelow: 0.8, ability: 'clones' }, ...]`), поэтому его бой
собирается из уже написанных способностей.

## Герой в бою

- Здоровье и силы — в `story.hero`: `{ hp, maxHp, stamina }`. Растут по сюжету (`{ add: { 'hero.maxHp': 20 } }`
  как награда), восстанавливаются едой, сном в домике, регенератором.
- Удар — урон `hero.strength` × множитель `weak.melee` цели. Серия из трех, третий удар отбрасывает.
- Вне боя здоровье тихо восстанавливается.

## Поражение

- **До браслета** (`onLose: 'wake'`): экран темнеет, герой приходит в себя у домика или у Дениса, прошло
  несколько часов, вещи на месте. Квест можно повторить.
- **С браслетом** (`onLose: 'rewind'`): перед началом каждой стычки делается автоснимок (core.md, сохранения);
  при смерти браслет тратит заряд, и мир возвращается к началу стычки, а герой «помнит»: в журнале
  остается запись, а подсказка становится точнее. Если заряда нет — как `wake`.
- В финале (5.02) браслет срабатывает последний раз: `rewindLimit: 1` у стычки.

## Новый бой

1. Если нужны новые существа — `defineCreature` в `src/content/creatures.js`.
2. Босс — `defineBoss`, стычка — `defineFight` в файле квеста.
3. Код — только если нужна новая способность или поведение (одна функция в библиотеке, контр-тег — в
   таблице) или новая 3D-модель.
